📖 AKL Move 설명서

🧭 메뉴

  • 📊 대시보드 — 주/월 합계, 잔디, 종목별 통계
  • ▶️ 새 기록 — GPS 자동 트래킹
  • 📋 히스토리 — 종목별 필터 + 경로 미니맵
  • 📅 스케줄 — 운동 예약 (언제 어디서)
  • 🎯 목표 — 주/월/연 목표 + 잔디 (셀 클릭 → 그날 기록)
  • 💰 예산 — 카테고리별 지출 + 월합계
  • 🍅 뽀모도로 — 운동 타이머 (외부 링크)

🎯 GPS 기록

  • 🚶 걷기 / 🏃 달리기 / 🚴 자전거 종목 선택
  • ▶️ 시작 — GPS 권한 허용 → 자동 기록 (Wake Lock으로 화면 유지)
  • ⏹ 종료 — 자동 저장
  • ✍️ 수동 입력 — GPS 없이 사후 거리/시간 입력

📊 계산 기준

  • 거리: GPS Haversine 공식 누적 (1m~200m 사이만 반영, 흔들림 필터)
  • 칼로리: MET × 70kg × 시간(h)
  • MET — 걷기 3.5 / 달리기 8.0 / 자전거 6.0

🎯 목표 + 잔디

  • 단위: km / 회 / 분 / kcal
  • 기간: 주간 / 월간 / 연간 (자동 집계)
  • 잔디 셀 — 일평균 목표 대비 진하기
  • 셀 클릭 — 그날(또는 그달) 기록 모달
  • ◀ ▶ — 이전/다음 기간 보기, "현재" 버튼으로 복귀
  • 목표는 1~3개가 적당 (많으면 흐려짐)

🏆 트로피 + 별점

  • 오늘의 별점 — 모든 목표 평균 (0~5★)
  • 계산: 오늘 누적 ÷ 일평균 목표 × 5
  • 예: 월 1000km 목표 → 일평균 33km → 오늘 33km 달성 = 5★
  • 📅 월별 일별 별점 잔디 (클릭 → 그날 상세)
  • 📊 통계: 🔥 연속 5★ / 🏆 5★ 일수 / 월평균 / 총 별

📊 대시보드 잔디

  • 셀 = 날짜 + ⭐별점 + 거리 + 시간 한 눈에
  • 오늘 셀은 그린 테두리 강조
  • 셀 클릭 → 그날 모든 세션 + 목표별 별점 모달

📅 스케줄

  • 예: "내일 19시 한강 자전거"
  • 날짜 지난 항목은 자동 흐림

💰 예산

  • 카테고리: 헬스장/장비/의류/신발/레슨/대회/기타
  • 이번 달 합계 + 카테고리별 분석 자동

📱 모바일 PWA

  • 브라우저 메뉴 → "홈 화면에 추가" → 앱처럼 사용
  • 화면 꺼짐 방지 (Wake Lock) 자동 작동
  • 오프라인에서도 캐시된 화면 열림 (저장은 온라인 필요)

🔋 팁

  • 도시 빌딩 사이는 GPS 흔들림 가능
  • 경로는 SVG로 압축 저장 (지도 없음, 가벼움)
  • 로그인 한 번 → 30일 자동 유지
